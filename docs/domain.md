# 领域说明

训练周期会带来装备、报名和旅行支出，家庭收入与应急储备又有固定优先级。计划日、银行价值日、比赛延期日和假设调整日可能不同，系统需要保留每次重排的依据。金额精度、扣款状态和目标版本属于长期留存的信息。

`reference/domain.json` 保存公开的目标类型、扣款状态、触发类型和日历精度约定。正式记录使用稳定标识，并区分三类时间：

- **业务时间（business_time）**：交易在来源时区发生的本地时间；
- **银行价值日（value_date / value_month）**：经过截止时间与工作日顺延后银行实际入账的日期，月度现金流按价值日归桶；
- **接收时间（triggered_at）**：系统收到事件并重排的时间，写入 adjustment。

## 关键不变量

1. `ledger` 为 append-only 事实账；已执行转账不被任何重排回算或覆盖。
2. 重排只作用于未来的 `scheduled` / `paused` 扣款；`executed` 与 `cancelled` 不可变。
3. 每次重排递增 `plan_version`，并把完整快照写入 `exports/plan_vN.json`，历史版本不可修改。
4. 银行流水以 `账户 + external_id`（缺失则行内容哈希）幂等去重。
5. 同一资金账户内的目标与收支假设币种一致；金额以 6 位小数精度的整数最小单位存储。
